# ІСККОН Чернівці — сайт храму

Статичний сайт Центру ведичної культури ІСККОН у Чернівцях (українською).
HTML + CSS + JS, без фреймворків і збірки.

## Структура

- `index.html` — головна: hero, розклад програм, «для кого», філософія,
  напрями служіння, фотогалерея, карта, відгуки, контакти
- `courses.html` — курси (ведична філософія, кулінарія, кіртан)
- `food.html` — благодійність «Їжа життя»
- `donation.html` — пожертви: кнопки WayForPay, QR-коди, банківські реквізити
- `assets/` — стилі, логотип, фото, QR-коди, `guide.js` (віджет помічника)
- `docs/` — брифы для редизайну (змагання Claude Code vs Codex)

## Деплой

Статика — достатньо скопіювати файли в корінь веб-сервера
(поточний продакшн: https://iskcon.cv.ua/).
Шляхи до ассетів абсолютні (`/assets/...`), навігація — `/`, `/courses`, `/food`, `/donation`
(на сервері — папки з `index.html` всередині).
