# Промпт для Claude Code (Opus 5.5) — второй макет iskcon.cv.ua уровня Awwwards

Подготовлено 22.10.2026 по итогам 6 параллельных исследований (папка research/ в проекте) и структурированных отзывов общины (files/structured-feedback-2026-10-22.md, research/02_feedback_structured.md).

Модель: главная — Claude Opus 5.5 (дизайн-решения, главная страница), рутина и скриншот-циклы — Sonnet 5.5, инвентаризация — Haiku 5.5.

## ШАГ 0. Установка стека (выполнить один раз, каждый инструмент — только одним каналом)

```bash
# 1. База вкуса Anthropic (только ОДИН из двух способов)
/plugin marketplace add anthropics/claude-code
/plugin install frontend-design@claude-plugins-official
# альтернатива: npx skills add anthropics/skills --skill frontend-design

# 2. Главный драйвер дизайна
npx impeccable install
# затем в сессии: /impeccable init   (режим: brand)
/impeccable document                  # сгенерировать DESIGN.md из существующего кода

# 3. Taste — ТОЛЬКО redesign для существующего проекта
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"

# 4. Проверяющий (не строитель)
npx skills add vercel-labs/agent-skills --skill web-design-guidelines -a claude-code

# 5. GSAP — частично, без React-частей
/plugin marketplace add greensock/gsap-skills
# брать: gsap-core, gsap-timeline, gsap-scrolltrigger, gsap-plugins, gsap-performance
# НЕ брать: gsap-react, gsap-frameworks. GSAP подключать только vendor/CDN-файлом, НЕ npm install.

# 6. Скриншот-цикл самопроверки
npx skills add https://github.com/anthropics/skills --skill webapp-testing
# Playwright MCP — опционально, вторым, с закреплённой версией (не @latest):
# claude plugin install playwright@claude-plugins-official --scope project

# НЕ УСТАНАВЛИВАТЬ: react-best-practices (нет React), 21st.dev Magic MCP (React/Tailwind-каталог),
# superpowers (второй планировщик, конфликтует с impeccable), Figma MCP (отложить до появления Figma-макета).
```

Ручки Taste для этого проекта: DESIGN_VARIANCE 6–7, MOTION_INTENSITY 4–5, VISUAL_DENSITY 2–3.
Принцип: один строитель, один проверяющий. Три вкусовых скила одновременно не включать.
После установки проверить `/context` — перебор скилов молча выпадает из бюджета контекста (~2%).

В CLAUDE.md проекта добавить блок исключений (не править сами SKILL.md, иначе drift-check):
«Stack: vanilla HTML/CSS/JS, без сборки. React, Tailwind, lucide-react и новые зависимости запрещены без отдельного согласования. Исключения из вкусовых скилов: шрифты и палитра — только из DESIGN.md ниже».

DESIGN.md (токены — дословно, не заменять на свои вкусы)

- Сетка: контейнер 1200px, текстовая мера 720px, ритм секций clamp(64px,10vw,128px);

  яркости по GSAP ScrollTrigger со scrub при скролле. Всё остальное — спокойная типографика и воздух.
  Анимации привязаны к скроллу, а не автоплей по загрузке. prefers-reduced-motion: всё статично.

- Текст, вшитый в фотографии, не переводится: такие подписи выносить в HTML.
