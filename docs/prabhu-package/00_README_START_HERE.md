## Твои действия по шагам (кратко, полная версия — файл 07)
1. `git clone` репозитория, `git checkout gh-pages`, ветка `mockup-v2`, тег `pre-redesign-snapshot`.
2. Положить 01_CLAUDE.md в корень как CLAUDE.md; остальные документы — в docs/prabhu-package/.
3. Открыть Claude Code в этой папке, модель Opus 5.5, вставить промпт из файла 02 — глубокий аудит.
4. Получить AUDIT.md, прислать его Прабху на сверку с исследованиями.
5. Установить скилы по файлу 03 (frontend-design, impeccable, Taste redesign, web-design-guidelines, GSAP частично, webapp-testing). НЕ ставить: react-best-practices, gsap-react, 21st.dev Magic MCP, superpowers, Figma MCP.
6. Запустить главный промпт из файла 03, работа срезами hero → главная → courses → food → donation.
7. Higgsfield — отдельным этапом после макета (промпты в research/05, пилот A+D1, лимит ~400 кредитов).
8. Превью в отдельном репозитории с noindex; мердж в боевой gh-pages — только после приёмки.
