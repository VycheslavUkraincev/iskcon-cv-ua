## 1. Короткий вывод

- Сайт — **полностью статичный**: HTML + CSS + JS, без фреймворков и без сборки. Всего 4 содержательные страницы, продублированные в двух вариантах вёрстки (см. п. 2.2).
- Контентное ядро компактное и ценное: расписание программ, «для кого», философия, 3 курса + библиотека, «Їжа життя» со статистикой и видео, пожертвования с рабочими платёжными механиками. **При редизайне это ядро сохраняется 1-в-1** (тексты, цифры, реквизиты, ссылки, QR, платёжные URL).
- Главная масса проблем — не контент, а **технический долг вёрстки**: дубли страниц `*.html` vs `*/index.html`, задвоенный `<base href="/iskcon-cv-ua/">`, смешанная модель путей (абсолютные `/assets/...` в документации против относительных `assets/...` в коде), 36,3 МБ изображений при том, что значительная часть файлов вообще не используется страницами.
- Отдельный, уже спроектированный в самом репозитории ориентир: `docs/brief-claude.md` требует при редизайне сохранить весь контент и украинский язык, не трогать блок пожертвований, сохранить виджет-помощник, остаться на чистом HTML/CSS/JS без внешних зависимостей.

### 2.3. Стек и общие элементы всех страниц

- **Стек:** чистые HTML/CSS/JS. CSS: `assets/style.css` (20 675 Б) + `assets/avatar.css` (7 115 Б). JS: `assets/site.js`, `assets/avatar.js`, `assets/i18n-dict.js` + `assets/i18n.js`. Единственная внешняя зависимость — Google Fonts, шрифт **Playfair Display 600/700** для заголовков; в CSS заголовки при этом дополнительно продублированы стеком Georgia/serif, системный sans для текста.
- **Палитра (CSS-переменные):** `--cream #FDF8EE`, `--card #FFFDF7`, `--line #EFE3CC`, `--saffron #D9820B`, `--saffron-dark #B36A06`, `--saffron-deep #b45309`, `--ink #2C2318`, `--muted #8A7660`, `--green #4E7A3A`. Контейнер `.wrap` — max-width 960px, центрирование `margin: 0 auto`.
- **Шапка (sticky header, одинаковая везде):** логотип `assets/logo.jpg` (44px) + «ІСККОН ЧЕРНІВЦІ», бургер-меню на мобильном, навигация: **Головна `./` · Навчання `courses` · Їжа життя `food` · Пожертви `donation`**, переключатель языков **UK / EN / RO**.
- **Подвал (одинаковый везде):** та же навигация из 4 пунктов, строка «РО «Релігійна громада свідомості Крішни в місті Чернівці» · ЄДРПОУ 46285356», адрес «вул. Скальда (Комарова), 40А, Чернівці · 063-311-7500».
- **SEO/social в `<head>`:** `lang="uk"`, description, `theme-color #D9820B`, Open Graph и Twitter Card, favicon = `assets/logo.jpg`. На главной дополнительно **JSON-LD Schema.org `HinduTemple`** с адресом, рейтингом 4.2 / 20 отзывов и `sameAs` (Instagram, Facebook-группа, Telegram, YouTube).
- **Виджет-помощник (на всех страницах):** живой аватар-вайшнав из `avatar.js/avatar.css` — видео-персонаж WebM с постером, сцена зависит от страницы (`main / learn / food / donate`: `avatar-main.webm`, `avatar-learn.webm`, `avatar-food.webm`, `avatar-donate.webm`, плюс `avatar-loop.*`), облачко с мантрой, состояния idle/waving/talking/happy/sleeping (засыпает через 60 сек бездействия), чат-дерево быстрых ответов: «Що таке ІСККОН?», «Коли найближча програма?», «Що таке «Їжа життя»?», «Які є курси?», «Як стати волонтером?» (с QR Telegram), «Як підтримати храм?».
- **Осиротевший код:** `assets/guide.js` (4 190 Б) + `assets/guide.css` (2 363 Б) — предыдущий вариант того же помощника (4 вопроса, без видео). **Ни одна страница его не подключает.** В брифе `docs/brief-claude.md` он ошибочно назван действующим виджетом — при редизайне ориентироваться на `avatar.js`, а `guide.*` выводить из эксплуатации осознанно.
- **Интерактив `site.js`:** тень шапки при скролле, мобильное меню, reveal-анимация секций через IntersectionObserver, самодельный lightbox галерей (стрелки, Esc, подпись «alt · n / N»).

## 7. Языки: UK / EN / RO

- **Исходный язык — украинский** (`<html lang="uk">`), все тексты в HTML написаны по-украински.
- **EN и RO — не отдельные страницы**, а клиентский перевод на лету: `assets/i18n-dict.js` — **91 928 Б, словарь примерно из 820 пар «украинская строка → перевод»** отдельно для `ro` и `en`; `assets/i18n.js` (5 201 Б) заменяет текстовые узлы и атрибуты `alt / title / aria-label / data-caption / placeholder`, а также `<title>` и meta description/OG.
- Выбор языка: кнопки UK/EN/RO в шапке, сохранение в `localStorage` (ключ `lang`), параметр `?lang=uk|ro|en`, динамическая смена `<html lang>` и `og:locale`, hreflang-ссылки скрипт добавляет сам на лету. MutationObserver для динамического контента (чат аватара) в текущем коде **закомментирован с пометкой «OBSERVER DISABLED FOR DEBUG»**, функции `observeOn/observeOff` — пустые заглушки: перевод динамически появляющихся узлов фактически не гарантирован.
- **Известный дефект из отзывов (подтверждён скриншотами `01_logo_uk.jpg`, `02_logo_ro.jpg`, `03_logo_en.jpg`):** логотип «Їжа життя» — статичная картинка (`ffl-logo`), подпись под солнцем остаётся украинской на RO и EN версиях. Предложенное в отзывах лечение — 3 языковых файла логотипа. Шире: та же болезнь у любого текста, запечённого в картинки (`goduy-molys.png` «Годуй · Молись · Люби», постеры аватара).
- Словарные шероховатости уже видны на живой выдаче: на `/food` блок фактов при переводе/рендере склеивается в «📍, Де, Соборна площа,, м. Чернівці, 🕒, Коли, щосуботи, о 14:00» — разметка карточек «место/время» хрупкая.
