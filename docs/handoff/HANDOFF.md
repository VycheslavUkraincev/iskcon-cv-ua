## 3. Как работает владелец (правила из диалога — соблюдать)
- Пишет по-русски; присылает задание блоком (часто «pasted»), с пунктами и **приёмкой**. Ответы — по-русски, кратко, с таблицами и **честными оговорками** («что не получилось», «что не проверено», «что решает владелец»). Не приукрашивать: если замер хуже цели — писать цифру и причину.
- Каждый срез заканчивается: отчёт `SLICEn_REPORT.md` → коммит → push **только `mockup-v2`** → обновление превью → ссылка → **СТОП**. Ничего сверх задания не реализовывать (например, рекомендации из `RECOMMENDATIONS_50.md` — только по команде).
- **Не выдумывать** факты, цифры, суммы, ссылки на формы, имена, даты. Нужны данные — писать «нужны данные владельца: …». Тексты под заголовками и контент не менять без разрешения; ключи словаря не удалять и не переименовывать, новые строки — **добавлениями** сразу в EN и RO.
- **Внешние и необратимые действия** (живой сайт, `gh-pages`, удаление файлов) — только после явного слова. Удалять ничего без слова (диск закончился один раз — владелец разрешил чистить **только мои временные файлы**; остальное — списком и ждать).
- Политика организации: не включать персональные данные и внутреннюю чувствительную информацию в публичное (поэтому в превью только файлы сайта).
- Прогон приёмки всегда: EN/RO — **0 кириллических узлов** (кроме 3 корешков книг `data-title` на `/courses`), Lighthouse mobile, скриншоты 1440/768/375, побайтная сверка платежей, регрессия других страниц (попиксельно).
- Любимые формулировки владельца: «срез», «СТОП после среза», «данные владельца», «инварианты», «честно отметь».

## 5. Текущее состояние кода (ключевое)
**Страницы** (теперь правятся вручную как обычный HTML; одноразовые генераторы `build2–5.py` из сессии **не перезапускать**, они перезапишут правки): `index.html`, `courses/index.html` (= `courses.html`, байт в байт), `food/index.html` (= `food.html`), `donation/index.html` (= `donation.html`), `404.html`. **Тело страницы:** `class="ds page-home|page-courses|page-food|page-donation|page-404"`. Весь новый CSS живёт в `assets/style.css` под `.ds` / `.page-*`; старые страницы больше не используют старые правила.
