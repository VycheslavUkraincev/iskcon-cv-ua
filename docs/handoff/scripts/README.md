# Скрипты проверок (вне сборки сайта)

Сохранены из рабочей сессии 22–23.10.2026. Это Node-скрипты на Playwright (системный Chrome, `channel:'chrome'`) и один Python. Они не часть сайта и не подключаются страницами.

Общее: `export T=<папка с node_modules: playwright, pngjs, jsqr>`; сервер сайта — `http://127.0.0.1:8765/iskcon-cv-ua/` (префикс `/iskcon-cv-ua/` нужен из-за `<base>`). Пути вывода и базы часто задаются переменными `S` (рабочая папка со `shots/`), `D`, `BASE`, `PAGE`, `NAME`, `TAG`; если скрипт ссылается на `process.env.S + '/shots/…'`, создайте папку заранее. Скрипты написаны под конкретные срезы и могут требовать правки селекторов.

| Файл | Назначение |
|---|---|
| `gz.js <папка> <порт>` | статический сервер с gzip (результаты Lighthouse ближе к GitHub Pages) |
| `av3.js` | чистый тест перекрытия аватара (учитывает overflow-обрезку), `WIDTHS`, `MARGIN` |
| `regr.js` | попиксельная регрессия страницы до/после (`BASE`, `PAGE`, `NAME`, `TAG`) |
| `cshots.js`, `fin.js`, `shots.js` | скриншоты (1440/768/375), замер контраста hero |
| `glowc.js` | контраст текста hero при максимуме эффекта «дыхание алтаря» |
| `verify.js` | проверка 4 страниц превью: статусы, ошибки, навигация |
| `inv2.py <до.html> <после.html>` | дифф текстовых узлов, атрибутов, ссылок и id |
| `t7.js`, `s6.js` | EN/RO без кириллицы, якоря, чат аватара, 404 |
| `f4.js`, `d5.js`, `d5m.js`, `c3.js`, `checks2.js` | поведенческие тесты `/food`, `/donation` (модалка, копирование), `/courses`, главной |
| `lcp2.js`, `br.js` | реальный LCP-элемент; поведение эффекта алтаря |

Одноразовые генераторы страниц (`build2–5.py`) сюда **не** включены намеренно: страницы теперь правятся вручную.
