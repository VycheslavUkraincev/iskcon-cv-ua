# Бриф для Claude Code — редизайн сайта ІСККОН Чернівці

## Контекст
Сайт храму ІСККОН у Чернівцях (українською). Статичний: HTML + CSS + JS, без фреймворків.
Репозиторій: клонируй, работай в ветке `claude-redesign`.

Структура:
- `index.html` — главная: hero, расписание программ, «для кого», философия, направления служения, фотогалерея, карта, отзывы, контакты
- `courses.html` — курсы (философия, кулинария, киртан)
- `food.html` — благотворительность «Їжа життя»
- `donation.html` — пожертвования: кнопки WayForPay, QR-коды, банковские реквизиты
- `assets/` — стили, логотип, фото, QR-коды, `guide.js` (виджет-помощник)
- `MEDIA.md` — инвентарь всех фото и медиа: что есть и откуда (прочти перед работой)

## Задача
Поднять дизайн до премиум-уровня современного сайта храма: тёплый, спокойный, дружелюбный,
но визуально сильный. Это соревнование: параллельно ту же задачу делает Codex — побеждает
лучший результат по критериям ниже.

## Что улучшить
1. Hero-блок: более выразительная композиция, типографика, настроение
2. Визуальная иерархия и ритм страницы, отступы, сетка
3. Микроанимации (появление блоков при скролле, hover-эффекты) — сдержанно, без цирка
4. Галерея: аккуратный lightbox вместо открытия в новой вкладке
5. Доступность: контраст, размеры шрифтов, семантика
6. Мобильная версия: всё должно идеально смотреться на телефоне

## Жёсткие ограничения (нарушение = дисквалификация)
- Весь контент и тексты сохранить (украинский язык)
- Не трогать блок пожертвований: ссылки WayForPay, QR-коды, реквизиты, кнопки копирования
- Пути к ассетам — абсолютные (`/assets/...`), навигация — `/`, `/courses`, `/food`, `/donation`
- Виджет-помощник (`guide.js`/`guide.css`) сохранить и не ломать
- Без фреймворков и сборщиков; только HTML/CSS/JS
- Не добавлять внешние зависимости, кроме уже подключённых

## Критерии оценки
Дизайн (40) · UX и мобильная версия (25) · Качество кода (15) · Полнота (все разделы работают) (10) · Детали и polish (10)
